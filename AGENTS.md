# Agent Instructions

## Project

`gtm-template-sandbox-types` is a TypeScript declaration package for Google Tag Manager template sandbox APIs. The published package contains only `types/`.

- `types/`: public declarations and package entry points.
- `README.md`: installation and usage examples.
- `CHANGELOG.md`: release history.
- `.github/workflows/`: versioning, release, publishing, SBOM, and attestation workflows.

## Changes

- Preserve the public exports in `package.json` (`.`, `./web`, and `./test`) unless the task explicitly changes the package API.
- Keep web and test declarations consistent when an API is shared by both contexts.
- Prefer focused declaration changes; avoid generated or unrelated formatting changes.
- Update README usage examples when a public type or package entry point changes.
- Preserve existing changelog release entries. Add new entries only when requested, using the existing release dates and Keep a Changelog categories.
- Do not edit `sbom.spdx.json` by hand; it is generated by the release workflow.

## Validation

Run the TypeScript declaration check from the repository root:

```bash
bunx tsc --noEmit
```

Use the repository's CI environment for release work:

```bash
bun install --frozen-lockfile
bun run build
```

Check `package.json` before relying on package scripts; the current package does not define local scripts.

## Git and Releases

- Do not commit, tag, publish, or push unless explicitly requested.
- Release workflows are manually dispatched and publish to both npm and GitHub Packages.
- Release notes are extracted from the versioned section in `CHANGELOG.md`.
